## 使用方法

1. 打开 Jupyter Lab（`jupyter lab`）
2. 按阶段顺序，逐个练习
3. 先看 Demo 理解概念，再独立完成练习，最后对答案
4. 每个练习标注了难度：⭐ 简单 ⭐⭐ 中等 ⭐⭐⭐ 挑战
